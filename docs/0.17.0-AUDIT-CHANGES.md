# Revit MCP 0.17.0 audit change log

25 November 2026. This is the file-by-file record of the systems and protocol audit patch. Paths are relative to the project root. Each entry identifies the previous behavior, the change, and its reason. Earlier development and live tests appear in the [project implementation log](IMPLEMENTATION_LOG.md).

## Python MCP server

| File | Action | What changed and why |
| --- | --- | --- |
| `server/server.py` | Edited | Added a FastMCP adapter that advertises closed outer argument schemas and validates them before SDK coercion. This catches misspellings such as `dryRun` that could otherwise disappear before dispatch. Unknown tool names now receive JSON-RPC error `-32602`. Registered tool calls have a limit of 240 per minute per server process. |
| `server/server.py` | Edited | Kept explicit empty or invalid parameter values distinct from omitted parameters. Rejected unknown batch and workbook-edit options, non-Boolean preview flags, preview flags inside individual operations, batches over 500 operations, and unknown or null purge options. These checks prevent malformed requests from falling back to a commit or a broader purge. |
| `server/server.py` | Edited | Made Excel import and operation batches mutually exclusive in the split edit tool. Rejected a workbook path without an Excel action and non-default units in the Excel branch, where they would be ignored. |
| `server/server.py` | Edited | Validated process IDs without floating-point conversion, rejected simultaneous PID and year selectors, skipped malformed session records, and returned the new selection state. This prevents selection of a different PID through truncation and fixes misleading status replies. |
| `server/server.py` | Edited | Updated the read tool's title and destructive hint because its exports can replace files. Added a per-request cancellation signal around worker execution. Translated rollback, preview, post-commit and workbook failures into MCP tool errors while retaining result details and available receipt IDs. |
| `server/bridge_client.py` | Edited | Validated connection objects, port and PID ranges, token and protocol types, and discovery filenames. Automatic selection can use a valid session when the default file is malformed. Explicit selection now captures connection identity and checks it on reuse so a recycled PID cannot silently redirect calls. |
| `server/bridge_client.py` | Edited | Added cancellation checks before selection and bridge dispatch. Replaced a per-read timeout with a deadline for the entire reply read while retaining the 128 MiB cap. Checked reply framing, request correlation, success-envelope fields and result types, and translated excessive JSON nesting into a bridge error. This prevents partial or malformed replies from appearing successful. |
| `server/bridge_client.py` | Edited | Recognized the native `outcome_unknown` receipt and surfaced the operation ID and PID for status lookup. An uncertain edit can now be investigated without submitting it as a new edit. |
| `server/request_lifetime.py` | Created | Added a context-local cancellation event and a checkpoint shared with worker threads. This lets a multi-step workflow stop before its next side effect after its MCP request ends. |
| `server/xlsx_util.py` | Edited | Check cancellation before creating the workbook destination and again after staging, immediately before publication. This stops a cancelled export from publishing when cancellation is already known at either boundary. |
| `server/excel_io.py` | Edited | Reject duplicate nonempty worksheet headers after trimming and case normalization. Previously the later column could silently replace the earlier value during row-to-dictionary conversion. |
| `server/catalog.py` | Edited | Corrected the tool description to disclose file writes and changes to Revit selection or session state. Clients now see the actual effects before calling the tool. |
| `server/requirements.txt` | Edited | Pinned the tested MCP SDK to 1.30.0 and declared the directly imported AnyIO and JSON Schema dependencies. The adapter relies on SDK handler behavior verified for that version. |

## Native Revit add-in

| File | Action | What changed and why |
| --- | --- | --- |
| `plugin/App.cs` | Edited | Stop the bridge and dispose the external event after startup failure. This cleans up resources created before a later startup step fails. |
| `plugin/Bridge/BridgeServer.cs` | Edited | Serialized checking, publishing and handing over the default session with a per-user Windows mutex, including bounded lock acquisition and recovery after an abandoned lock. Set a socket write timeout and discard unterminated request lines at EOF. These changes address ownership races, blocked writers and accidental dispatch of incomplete frames. |
| `plugin/Bridge/EditReceipts.cs` | Edited | Record an unhandled exception after execution starts as a terminal unknown outcome. Preserve retry behavior for pre-dispatch failures and pending permission. Cap reserved IDs at 65,536 per process and refuse new IDs when full so memory is bounded without losing duplicate-edit protection. |
| `plugin/Core/Json.cs` | Edited | Tightened the private bridge parser to accept JSON number syntax, reject numeric overflow to infinity and raw control characters, and require four hexadecimal digits in Unicode escapes. This prevents invalid wire values from reaching handlers. |
| `plugin/Core/Args.cs` | Edited | Added a shared conversion that accepts only whole numbers representable as signed 32-bit integers. It prevents rounding or unchecked conversion when a Revit API requires an integer. |
| `plugin/Edit/DataOps.cs` | Edited | Used the checked conversion for global integer parameters so the model receives the value the caller specified. |
| `plugin/Edit/DepthOps.cs` | Edited | Used the same checked conversion for integer schedule filters so a fractional or out-of-range value cannot silently change filter criteria. |
| `plugin/Edit/EditEngine.cs` | Edited | Rejected unrecognized batch keys, explicit null preview flags and preview flags nested in operations at the native entry point. Direct bridge clients now receive the same protection against unintended commits. |
| `plugin/Edit/ManageOps.cs` | Edited | Rejected unknown and null purge options before candidate evaluation or deletion. A misspelled category or keep-list argument can no longer silently broaden the operation. |
| `plugin/Core/Describe.cs` | Edited | Extracted a shared bounding-box transformation that composes the box and caller transforms and considers all eight corners. The identity shortcut now uses the combined transform. |
| `plugin/Read/DepthRead.cs` | Edited | Reused the eight-corner helper for solids, accumulated volume before rounding and passed the transform directly into traversal. These changes correct rotated bounds and totals for collections of small solids. Added traversal limits of 64 nesting levels and 100,000 objects, with an explicit failure when exceeded. |
| `plugin/Read/DepthRead.cs` | Edited | Indexed group instances by type and views by assembly once per request. This removes repeated full scans on Revit's UI thread. |

## Tests, packaging and documentation

| File | Action | What changed and why |
| --- | --- | --- |
| `tests/live_p89.py` | Edited | Pinned the harness to the initially checked Revit connection and document ID and used a unique temporary export directory. Made failed post-commit work fail the check and returned a nonzero exit status for failed checks. This protects the intended model and makes failures visible to automation. |
| `tests/fake_bridge.py` | Edited | Added a deterministic rollback response so the MCP execution-error and receipt behavior can be tested without Revit. |
| `tests/smoke_test.py` | Edited | Added regressions for fractional PIDs, null or misspelled preview flags, ambiguous Excel and operation inputs, and rollback errors carrying a receipt ID. Launched the fake bridge with the base interpreter so Windows test assertions compare the actual bridge PID with the session file. |
| `build_package.bat` | Edited | Propagated per-year compiler and copy failures to the overall package build and made subroutine exit statuses explicit. A failed rebuild or staging copy previously could still produce an apparently successful package. |
| `docs/PROTOCOL_AUDIT.md` | Created | Recorded severity, affected code, consequences, corrections, remaining risks, specification references and verification coverage. |
| `docs/IMPLEMENTATION_LOG.md` | Edited | Added the dated audit entry to the project's continuing implementation history. |
| `docs/0.17.0-AUDIT-CHANGES.md` | Created | Collected the individual changes and their reasons in this standalone record. |

No files were deleted in the audit patch.

## Verification recorded during the audit

* Revit 2024 and 2027 Release builds each completed with zero warnings and zero errors.
* The MCP smoke suite passed, including two simulated Revit sessions, workbook workflows, input rejection and rollback receipts.
* A separate stdio subprocess check passed initialization, the initialized notification, numeric and string request IDs, ping, tool discovery, unknown-tool error handling and clean EOF. It observed no extra stdout.
* The bar-stock regression checks and the temporary-directory deployment, rollback and retry checks passed.
* Live verification of these patched DLLs and end-to-end testing of a newly packaged executable and installer remain pending. The [audit report](PROTOCOL_AUDIT.md) records the open implementation work.
