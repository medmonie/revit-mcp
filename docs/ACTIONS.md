# Actions and edit operations

Generated from `server/catalog.py` by `tools/gen_docs.py` - do not edit by hand.

Everything goes through one MCP tool: `revit(action, params)`. A parameter ending in `?` is optional.

UNITS: every length and coordinate you send or receive is in millimetres unless params.units says otherwise (mm | cm | m | ft | in; for an edit it applies to the whole batch). Take-off lengths are metres, areas m2, volumes m3, rebar weight kg, angles degrees. Coordinates are relative to the Revit internal origin; z defaults to the level.

## The `edit` action

Change the model or write files. The server captures the active document before editing. Pass document_id from an earlier ping to require that model. operation_id (generated when omitted) lets a retry after a lost reply return the first result instead of editing twice (reuse it only with the identical request), and get_operation_status reports it. If an edit call times out or is cancelled, the edit may still have been applied: call get_operation_status (no operation_id lists recent writes) before sending it again. If an edit call times out or is cancelled, the edit may still have been applied: call get_operation_status (no operation_id lists recent writes) before sending it again. Model edits run in one transaction. Dry runs list first-pass purge candidates and roll back simulated model changes. Saving and exporting run after commit and report their own outcomes in postCommit. Editing needs a ONE-TIME permission per Revit session: the first edit returns at once with permission 'not granted' and opens a Yes/No dialog in Revit (or the user presses Add-Ins > Claude MCP > Allow Editing). Ask the user to click Yes, confirm with get_edit_permission, then send the edit again as a new request.

## Worksharing actions (4) - change the central model

These talk to the central model, cannot be undone and have no dry run, so each is its own action (never inside edit). They need the same one-time edit permission. sync_with_central and relinquish also need confirm: true: ask the user first, every time. Revit then shows its own Yes/No dialog for that one action: the first call returns permission 'not granted'; after the user clicks Yes, send the same request again within 5 minutes. Pass document_id from ping to make sure the right model is synced.

| Name | Parameters | What it does |
|---|---|---|
| `sync_with_central` | `confirm` true, after the user agreed to this sync<br>`comment?` sync comment<br>`relinquish?` all (default) \| borrowed (elements only, keep worksets) \| none<br>`compact?` default false<br>`save_local?` default true: save the local file before and after (always on for cloud models, Revit requires it)<br>`document_id?` documentId from ping<br>`operation_id?` request ID | Synchronize the active workshared model with its central (server or Autodesk Docs): send your changes, receive others', relinquish by choice. Reports what you held before and after. |
| `reload_latest` | `document_id?` documentId from ping<br>`operation_id?` request ID | Bring other users' synced changes into this model (no changes are sent). |
| `relinquish` | `confirm` true, after the user agreed<br>`what?` all (default) \| borrowed (elements) \| worksets<br>`document_id?` documentId from ping<br>`operation_id?` request ID | Give back what you hold in the central model without synchronising (only what is not modified locally). |
| `checkout` | `ids?` list of element ids<br>`worksets?` workset names<br>`document_id?` documentId from ping<br>`operation_id?` request ID | Take ownership of elements and / or worksets in the central model before editing them. |
