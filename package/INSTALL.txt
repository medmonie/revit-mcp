Revit MCP bridge - quick install (Revit 2024 / 2027)

Needed on this PC: Autodesk Revit 2024 and/or 2027, and an MCP client (Claude Desktop, ChatGPT desktop or Codex).
Nothing else: the package includes the MCP server as one exe. Python and the .NET SDK are only for building from source.

1. Close Revit.
2. Unzip RevitMcp.zip and double-click install.bat. It
   - installs the add-in for each Revit it finds (%APPDATA%\Autodesk\Revit\Addins\<year>\),
   - installs the server: %LOCALAPPDATA%\RevitMcpBridge\revit-mcp-server.exe,
   - adds "revit" to Claude Desktop (claude_desktop_config.json) and Codex (~/.codex/config.toml), keeping your
     other servers (civil3d ...); the old file is saved next to it as .bak-<date>.
3. Fully quit Claude Desktop (tray icon > Quit) and start it again.
4. Start Revit. When it asks about loading "Revit MCP bridge", choose Always Load. A Claude MCP panel appears on the
   Add-Ins tab.
5. Open a model and ask: "Ping Revit and tell me which model is open."

ChatGPT desktop: Settings > MCP servers > Add server. Name it revit, choose STDIO, command = the server path printed by
install.bat, no arguments. Save and restart as prompted.
If install.bat could not change a client's settings, add this by hand (snippets are saved next to the server):
  Claude Desktop (Settings > Developer > Edit Config), inside "mcpServers":
    "revit": { "command": "C:\\Users\\<you>\\AppData\\Local\\RevitMcpBridge\\revit-mcp-server.exe" }

Permissions
- Your MCP client asks before it uses the tool. Revit asks once per session, at the first edit.
- Add-Ins > Claude MCP > Allow Editing allows editing without the dialog; Stop Editing switches it off.

Updating: close Revit and the MCP client, run the new install.bat, then start both again.
Uninstall: run uninstall.bat (removes the add-in, the server and the revit entry from Claude Desktop and Codex).
Log of the last install: install_result.txt next to install.bat.
